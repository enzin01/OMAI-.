# Digital Foundation

Site institucional premium, pronto para usar como link principal na bio do Instagram.

## Como publicar

1. Suba este projeto em uma conta da Vercel.
2. Use o comando de build padrão: `npm run build`.
3. A saída estática é gerada na pasta `out`.
4. Depois de publicado, copie a URL final e coloque no campo "Site" da bio do Instagram.

## WhatsApp

Todos os botões principais usam o número `1199551-2411` com mensagem automática:

`Olá, vim pelo site da Digital Foundation e quero solicitar um orçamento para meu projeto digital.`

## Preview local

Depois de rodar `npm run build`, use:

```bash
npm run preview
```

O site abre em `http://127.0.0.1:3000`.
